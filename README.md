# 吴昊天 · Haotian Wu

Personal website at https://christopherhaotianwu.github.io/.

Static bilingual website, generated by GitHub Pages' built-in Jekyll pipeline. The public site needs no application server, database or external font service. Pages CMS provides browser-based editing.

## Edit

- `_data/zh.json` and `_data/en.json`: Chinese and English content.
- `.pages.yml`: Pages CMS form schema, with editable paragraphs and repeatable project, experience, research and education lists.
- `_includes/home.html`: shared, escaped Liquid template.
- `index.html` and `en/index.html`: language routes.
- `styles.css`: bilingual responsive layout and A4 print styles.
- `script.js`: opens the browser's print dialog to print or save as PDF.

Content based on the owner's résumé updated 2026-10-20 and the public CortexCrawl README. Research submission/draft labels are preserved. Review dates and research status when updating the site.

## Preview

For local development, use Jekyll to render Liquid and data files before starting an HTTP server. Serving this source directory directly will not render the templates. GitHub Pages builds the published site automatically.

## Edit in a browser

Open https://christopherhaotianwu.github.io/admin/ and follow the Pages CMS link. After the one-time GitHub App setup, choose this repository and `master`, then `中文主页` or `English homepage`. Change a field, add/reorder a list entry, and save. The save commits content; GitHub Pages rebuilds and publishes it. Chinese and English are edited independently, with no automatic translation.

Authorize Pages CMS only for `ChristopherHaotianWu.github.io`. Review the live GitHub consent page before granting access. The website does not contain credentials or a custom authentication implementation. Access can be revoked in GitHub Settings → Applications. Content remains in the repository if the CMS is unavailable.

## Deploy

In repository Settings → Pages, use **Deploy from a branch**, select **master** and **/(root)**. Updates to master automatically publish to GitHub Pages. Do not add `.nojekyll`: this site uses Liquid and `_data` files.
